# Tribute Website — Dr. Abdul Qadeer Khan

A simple, responsive tribute webpage dedicated to Dr. Abdul Qadeer Khan, 
the renowned Pakistani nuclear physicist. This project was built to 
practice semantic HTML and CSS layout skills — including flexbox, 
custom styling, and clean content structuring.

## 🔧 Built With
- HTML5
- CSS3

## ✨ Features
- Clean, readable layout with sections for biography and background
- Responsive image styling
- External link to Wikipedia for further reading

Built in August 2025 as part of my front-end web development practice.
